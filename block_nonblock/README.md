# 阻塞赋值与非阻塞赋值对比

图片中的两段逻辑都在 `tb.v` 中，共用 `clk`、低有效异步复位 `rst_n` 和复位输入 `a_i`、`b_i`。
命名块分别为 `x_block` 和 `x_nonblock`，各自保留独立的 `a`、`b`；GTKWave 也按这两个名称分组显示。
`gtkwaverc` 设置白色背景、黑色信号和浅灰色网格，`make run` / `make wave` 自动加载。

```sh
make run           # 编译、仿真，并打开已分组的波形
make sim           # 只仿真，生成 build/wave.vcd
make wave          # 打开已有波形
make check         # Verilator lint、Icarus 仿真、Verilator 仿真
```

第一轮复位输入为 `(a_i,b_i)=(1,0)`，释放复位后的结果为：

| 时刻 | x_block.a | x_block.b | x_nonblock.a | x_nonblock.b |
| --- | --- | --- | --- | --- |
| 复位后 | 1 | 0 | 1 | 0 |
| 第 1 个上升沿后 | 0 | 0 | 0 | 1 |
| 第 2 个上升沿后 | 0 | 0 | 1 | 0 |
| 第 3 个上升沿后 | 0 | 0 | 0 | 1 |

`a = b; b = a;` 中，第二句读取的 `a` 已被第一句改写，因此两者都变成原来的 `b`。
`a <= b; b <= a;` 中，两个右值都在本次执行时读取，左值在非阻塞赋值阶段更新，因此交换沿前的值。

第二轮改用 `(a_i,b_i)=(0,1)` 再次异步复位并运行，检查阻塞赋值结果为 `(1,1)`、非阻塞赋值继续交替交换。
每轮检查复位下降沿后的立即加载、复位保持和释放后的 6 个周期；比较均等待 1 ns，避开非阻塞赋值更新阶段。
